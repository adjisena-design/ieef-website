# IEEF website

Rebuild of [ieef.or.id](https://ieef.or.id) for the Institute for Energy, Economics & Finance, using the approved **Plan B** design (painted landscape + glass).

- **Stack:** [Astro](https://astro.build) (static HTML, free and open source) · Plus Jakarta Sans · Supabase for content and the team console (from step 2)
- **Languages:** English at `/`, Bahasa Indonesia at `/id/` with an EN/ID toggle on every page
- **Hosting:** Cloudflare Workers (free tier), password-protected preview until launch

## Run locally

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs static site to dist/
```

## Deploy (Cloudflare Workers)

The site deploys as a Cloudflare Worker with static assets (`wrangler.jsonc`). Every push to `main` rebuilds automatically.

| Setting (Worker → Settings → Build) | Value |
|---|---|
| Build command | `npm run build` |
| Deploy command | `npx wrangler deploy` |
| Root directory | `/` |

| Variable (Worker → Settings → Variables and Secrets) | When |
|---|---|
| `PREVIEW_PASSWORD` (type: Secret) | Preview: the team password. Any username works. |
| `PUBLIC_INDEXABLE=true` (build variable) | Launch only, together with deleting `PREVIEW_PASSWORD` |

`worker/index.js` checks the password on every request, then serves the built files from `dist/`. `keep_vars` in `wrangler.jsonc` keeps dashboard variables across deploys.

Test locally: `npm run build && npx wrangler dev --var PREVIEW_PASSWORD:test`

## Content and database

- `supabase/migrations/` holds the schema: people, publications (policy briefs + research), news, careers, partners, contact messages, and the public `media` storage bucket. Row-level security: the public reads published rows only; only signed-in console editors can change content or read contact messages.
- `supabase/seed.sql` is the one-time import of the old site's content (generated by `migration/make_seed.py`).
- `src/lib/content.ts` reads Supabase at build time when `PUBLIC_SUPABASE_URL` and `PUBLIC_SUPABASE_ANON_KEY` are set, otherwise the snapshot in `src/data/snapshot/`.
- Image fields hold `repo:<path>` (optimised file in `src/assets`, used for migrated content) or a path in the `media` bucket (console uploads). See `src/lib/media.ts`.
- `migration/` keeps the raw capture of the old site, the parser, and `issues.md` (problems found on the old site).
- The Worker pings Supabase every 3 days so the free project never pauses.

## Policy-brief covers

Covers are drawn by the site (`BriefCover.astro`) over a painted scene from `src/assets/art/scenes/`: solar, school, city,
port, offshore-wind, grid, rec-singapore, ev-road, ev-city, hydro-village. Each brief stores its scene in
`publications.cover_scene`; if empty, a scene suiting the brief's theme is used; an uploaded `cover` image overrides both.
Scenes are generated by `migration/cover-scenes/scenes.py` (stipple style, motifs kept below the title area).

## Design rules (Plan B)

- Brand colours come from the logo and do not change: navy `#083868`, teal `#189080`, mint `#78C0B8`, sky `#5898C0`.
- Painted art carries heroes, section breaks and publication covers. Glass sits only behind text and data: paper glass on light art, navy glass on dark art.
- Warm `#EC9A4C` is reserved for the primary call to action and the sun.
- Policy-brief series colours: energy & finance teal, social policy dawn `#B4602A`, regional economy dusk `#2D4AA0`.
- Art ships as WebP at several widths (AVIF tested larger on the grainy texture).

## Team console

`/console` is a static page that talks to Supabase from the browser. It works like the Jabar Open panitia console:

- A visitor gets an anonymous Supabase session (Authentication setting "Allow anonymous sign-ins" must stay on). Entering an access code (`IEEF-XXXX-XXXX`) links that session to a row in `cms.staff` for 12 hours.
- Roles: **owner** (one, cannot be revoked; manages admin codes and the deploy hook), **admin** (manages editor and contributor codes, deletes content), **editor** (edits content, reads messages, approves drafts, publishes), **contributor** (submits drafts and suggested edits to `cms.drafts`).
- Codes are stored only as SHA-256 hashes; a new code is shown once. Revoking ends the holder's sessions immediately.
- Editors write to the content tables directly through RLS (`private.is_editor()`); all changes are logged in `cms.log` by trigger.
- **Publish** calls `console_publish()`, which POSTs to the Cloudflare Workers Builds deploy hook stored in `cms.settings` (never in the repo) via `pg_net`. The site rebuilds from the database in about 10 minutes.
- Schema and functions: `supabase/migrations/20261028000005_console.sql`. UI: `src/pages/console.astro`, `src/console/`.
